## 维护约定

1. **本仓库内所有文档的相对路径都相对于仓库根目录**（如 `doc/01-...`、`app/...`），
   不要写成 `../doc/...`。
2. **契约的唯一权威来源是代码**：
   - 请求 / 响应模型 → `app/schemas/chat.py`
   - 推理档位与参数 → `app/llm/profiles.py`
   - 错误码 → `app/core/envelope.py`
   文档与代码冲突时**以代码为准**，并回来修文档。
3. 改动时的同步关系：

   | 改了什么 | 要同步 |
   | --- | --- |
   | 接口字段 / 错误码 / SSE 协议 | `01`、`../README.md` |
   | 部署方式 / 环境变量 | `../README.md` §4、`../.env.example` |
   | 人格提示词结构 | `02` §4、`../prompts/paimon.json`、`../db/migrations/` |
   | 阶段排期 / 决策 | `05` |
   | 阿里云资源与费用 | `06` |

4. **新增文档后要回来更新本索引**（含上面的「按场景跳转」表），否则索引会腐化。
5. 不要在本目录放临时文档或草稿，用完即删。
